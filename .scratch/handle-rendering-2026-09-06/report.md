# Готовность геометрии нод и хендлов

## Симптомы

В Stress test линии появлялись до кастомных нод; хендлы иногда оказывались выше середины карточки.

## Воспроизведение

`npx ng test ngx-vflow-lib --watch=false --browsers=ChromeHeadless --progress=false --include='**/initial-handles.spec.ts'`

До исправления: **2 FAILED, 4 SUCCESS**. Минимальный граф из двух кастомных нод показывал линию при скрытых нодах. Изменение zoom колесом непосредственно перед отложенным замером давало `top: 36.3772px` вместо `48px` у контейнера высотой 96px. Тест использует настоящий DOM, ResizeObserver и D3 wheel; перехватывается только момент выполнения очереди измерений, чтобы воспроизвести порядок событий детерминированно.

На реальной странице с 1024 кастомными нодами также зафиксирован первый видимый кадр с `top: auto`: центр хендла на 7px выше середины карточки. Следующий кадр — `top: 24px`. Таким образом, прежняя проверка холодного старта в TestBed пропускала наблюдаемый в demo случай.

## Причины и исправление

1. Регистрация HandleModel делала ребро доступным для отрисовки раньше измерения размеров и точек подключения. Теперь видимость рёбер и их HTML-подписей зависит от готовности обеих нод.
2. ResizeObserver выставлял готовность размеров ноды независимо от очереди измерения хендлов. Теперь NodeModel.isReady требует и размеры, и геометрию всех текущих хендлов. При виртуальном удалении сохраняются предыдущие размеры и геометрия для пересекающих viewport рёбер; новый DOM при возврате измеряется заново.
3. Событие zoom изменяет сигнал синхронно, а Angular применяет CSS transform позже. Деление старых DOM-координат на новый zoom давало неверную позицию. HandleModel теперь читает масштаб из фактически применённого transform viewport.

После исправления первые кадры demo: скрытые ноды, 0 видимых линий; затем видимые ноды с `top: 24px`, центр совпадает, 1023 видимые линии. Проверка в `e2e/stress-rendering.spec.ts` обходит все 1024 ноды в первых восьми кадрах и остаётся в наборе e2e.

Это исправление порядка отображения и измерения. Новый прирост FPS не заявляется. Для предотвращения повторения регрессии готовность геометрии учитывается явно, а первые кадры проверяются на реальной странице, дополнительно к TestBed.
