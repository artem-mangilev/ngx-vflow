# Логотип vflow: правила

Знак — квадрат, круг и треугольник, перетекающие друг в друга: узлы и связи между ними. Надпись — «vflow».

## Файлы

| Нужно                                           | Файл                                                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Знак на светлом фоне                            | `mark-light.svg`                                                                                  |
| Знак на тёмном фоне                             | `mark-dark.svg`                                                                                   |
| Знак одним цветом                               | `mark.svg` — цвет берётся из текста вокруг, если SVG вставлен в разметку; через `<img>` он чёрный |
| Знак с надписью                                 | `lockup-light.svg`, `lockup-dark.svg`, одним цветом — `lockup.svg`                                |
| Знак на плашке — там, где фон чужой или пёстрый | `tile-dark.svg`, `tile-light.svg`                                                                 |
| Вкладка браузера                                | `favicon.svg`, запасной `favicon.ico` (16, 32, 48 px)                                             |
| Иконка iOS                                      | `apple-touch-icon.png`, 180 px                                                                    |
| Аватар (npm, Discord, GitHub)                   | `avatar.png`, 512 px                                                                              |
| Превью ссылок                                   | `og.png`, 1200×630                                                                                |
| Обложка репозитория GitHub                      | `github-cover.png`, 1280×640                                                                      |

## Размер и поля

- Знак — не меньше 16 px. В этом размере шейка между фигурами равна 1,9 px; мельче связь пропадает.
- Связка — не меньше 20 px в высоту.
- Свободное поле вокруг знака и связки — четверть высоты знака со всех сторон.
- На плашке знак занимает 60% стороны: так он переживает круглую обрезку аватара.

## Цвет

| Роль                            | Значение                                     |
| ------------------------------- | -------------------------------------------- |
| Градиент на светлом фоне        | снизу `#3282b8`, сверху `#0f4c75`            |
| Градиент на тёмном фоне         | снизу `#bbe1fa`, сверху `#3282b8`            |
| Надпись                         | `#1b262c` на светлом, `#ffffff` на тёмном    |
| Тёмная плашка и фон превью      | `#1b262c`                                    |
| Один цвет для неизвестного фона | `#3282b8` — читается и на белом, и на чёрном |

Градиент всегда вертикальный, светлый конец внизу. Одноцветная версия равноправна: её берут там, где градиент не воспроизвести или фон неизвестен.

## Надпись

Geist Sans Bold (вес 700), в файлах — в кривых. При знаке высотой 64: кегль 56, трекинг 0, зазор до знака 20, слово выровнено по центру знака. Кернинг — из шрифта.

## Нельзя

- Ставить светлый градиент (`mark-light`) на тёмный фон: верх `#0f4c75` даёт контраст 2,2:1.
- Менять цвета градиента, его направление, добавлять тени, обводки, свечение.
- Растягивать, поворачивать, отражать знак, менять порядок или расстояние фигур.
- Писать «ngx-vflow» в связке, набирать надпись другим шрифтом, ставить текст внутрь фигур.
- Использовать щит, шестиугольник и красный цвет Angular рядом со знаком как часть логотипа.

## Как пересобрать

Из папки `.scratch/logo-2026-11-25`, по порядку:

1. `python3 build-mark.py` — знак, плашки, `favicon.svg`. Размеры фигур и ширина шейки заданы в начале скрипта.
2. `python build-lockup.py` — связка. Нужны `fonttools` и `brotli`, шрифт берётся из соседнего `vflow-studio`.
3. `node build-raster.mjs` — PNG и ICO, через Chromium из `apps/docs-e2e`.

На сайте документации лежат копии: `apps/docs/src/favicon.svg`, `favicon.ico`, `assets/logo.svg`, `assets/lockup.svg`, `assets/lockup-dark.svg`, `assets/apple-touch-icon.png`, `assets/og.png`. После пересборки их надо скопировать заново.
