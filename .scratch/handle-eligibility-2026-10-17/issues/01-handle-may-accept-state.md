# 01. Состояние «может принять» у handle во время протягивания связи

Status: needs-triage
Type: task

## Зачем

Сейчас `HandleState` (`connecting | valid | invalid | idle`) описывает только handle, от которого тянут связь, и кандидата под указателем. Пока указатель не дошёл до порта, пользователь не знает, какие порты примут связь. Unreal Blueprints, ComfyUI/LiteGraph и FigJam подсвечивают подходящие цели, а неподходящие приглушают на всё время жеста. Без этого в графе с типизированными портами (демо pipeline) связь ищут перебором.

Вид уже выбран в матрице вариантов `vuiPort` (вариант B, 2026-10-17): подходящая цель — кольцо 8px в цвете selection, неподходящая приглушена. Нужен сигнал из core и стили в `vuiPort`.

## Что сделать

- Во время `connection-start` и `reconnection-start` у каждого handle, кроме источника и текущего кандидата, есть признак применимости: `eligible` (кандидат был бы `valid`) или `ineligible`. Форма API — на триаже: новые значения `HandleState`, либо отдельный сигнал и атрибут `data-v-handle-eligible`, чтобы не менять смысл `state` у существующих потребителей.
- Применимость вычисляется **один раз при старте жеста** для всех handle, а не на каждом движении указателя. `isValid` в `connection-controller.directive.ts` сейчас перебирает все рёбра на каждый вызов (проверка дубликатов). Для всех handle это O(H·E), поэтому дубликаты нужно проверять по `Set` ключей связей, построенному один раз. См. ловушку O(n²) с `isValidLink` (performance-2026-09-26).
- Правила те же, что у кандидата: `canAccept`, `adjustDirection` для типизированных handle, `allowDuplicateConnections`, валидатор приложения. Валидатор вызывается по одному разу на handle за жест; это надо задокументировать, потому что сейчас он вызывается только для кандидата.
- Handle скрытых (culled) узлов: признак ставится, когда узел появляется. Пересчитывать всё на каждом кадре pan нельзя.
- Сброс в конце жеста и при отмене (Escape, pointercancel).
- `vuiPort`: `eligible` — рамка selection без заливки, `ineligible` — `opacity` ~0.4, без halo. `vuiPortReveal="interaction"` показывает подходящие порты всех узлов во время жеста.

## Готово, когда

- Unit-тесты connection controller: признак ставится на старте, валидатор вызывается не больше одного раза на handle за жест, сброс после connect, cancel и reconnect.
- Демо pipeline: при протягивании от видео-выхода подсвечены только видео-входы.
- Замер на stress-странице: старт жеста на 1000 узлах не даёт long task больше 50 мс.
