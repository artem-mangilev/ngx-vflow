# Scroll/collapse: результаты эксперимента

Дата: 2026-09-12, этап 5. Эксперимент выполнен локально в демо `ScrollCollapseDemoComponent` на странице ERD; это не библиотечный контракт и не основание для нового публичного API.

## Что проверено

| Сценарий                                    | Результат                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Сохранение модели и IDs при collapse/expand | Поля и рёбра не меняются; UI не удаляет и не пересоздаёт связи.                                                                                                                                                                                                                                                                                                                                                          |
| Collapse                                    | Строки не рендерятся; в заголовке рендерятся proxy handles с теми же ID (`in:`/`out:`), все рёбра остаются присоединёнными к заголовку. Проверено e2e: точка начала ребра совпадает с портом заголовка с точностью < 1.5px.                                                                                                                                                                                              |
| Expand                                      | Строки рендерятся заново, endpoints возвращаются на строки по тем же ID. Проверено e2e.                                                                                                                                                                                                                                                                                                                                  |
| Scroll внутри ноды                          | Строки остаются смонтированными в `overflow-y: auto`. Core позиционирует handles в системе координат ноды по измерениям после render и resize и не слушает scroll: без вмешательства handles прокрученных строк остаются на старых местах и рисуются за пределами ноды, а handle видимой строки не следует за строкой. Измерено скриптом: после прокрутки на 120px и edgeY, и portY остались прежними при scrollTop 120. |
| Политика демо для scroll                    | Скрытые сверху строки отдают endpoints proxy handles в заголовке, скрытые снизу — в подвале («перенос к границе»); видимые строки пересоздаются при scroll, чтобы core измерил их заново. Проверено e2e: ребро к строке под областью прокрутки начинается в подвале, ребро к видимой строке — на строке.                                                                                                                 |
| Zoom                                        | Endpoints остаются на видимых строках при любом масштабе; прокрутка и zoom независимы.                                                                                                                                                                                                                                                                                                                                   |
| Конфликт жестов                             | Без `vflowNoWheel` колесо над строками зумит граф. С `vflowNoWheel` колесо прокручивает строки, transform viewport не меняется. Проверено e2e.                                                                                                                                                                                                                                                                           |

## Ограничения подхода демо

- Proxy handles при collapse — приём приложения: оно само рендерит handles с прежними ID в заголовке. Библиотека не переносит endpoints автоматически.
- Пересоздание строк при scroll — приём демо для повторного измерения; на больших списках он дорог. Политика для библиотеки (наблюдать scroll, переносить к границе, скрывать) — отдельное решение; из эксперимента она автоматически не следует.
- Hit-область скрытых портов внутри overflow-контейнера обрезается вместе с портом.
