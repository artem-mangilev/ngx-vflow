# Alignment helper: снап в drag-конвейере, равные промежутки, прямые рёбра

Дата: 2026-09-27. Ветка `claude/alignment-helper-improvements-87d69d`. Исследование и сводка по инструментам — `research.md`.

## Решения

- **D1. Снап внутри drag.** `DraggableService.moveTo` считает сырые позиции drag-набора, выравнивает bounding box набора, сдвигает все узлы на одну дельту, применяет сетку и `extent`. Снап живой; подписка хелпера на `node-drag-end` и `setPoint` на drop удаляются.
- **D2. Порог в экранных px.** `tolerance` (по умолчанию 10) делится на zoom. Смысл настройки меняется — строка в миграции.
- **D3. Кандидаты.** Узлы во вьюпорте на старте drag, минус drag-набор и **все** его потомки. Предки узлов drag-набора дают только центральные оси. Узлы в других родителях — полноценные кандидаты.
- **D4. Якоря.** Центр↔центр и край↔край (4 пары на ось). Перекрёстных край↔центр нет.
- **D5. Выбор снапа.** По каждой оси — минимальный |сдвиг| среди всех видов снапа (линии, промежутки, handle) в пределах порога.
- **D6. Направляющие — второй проход.** После сдвига, сетки и `extent` показываются только точные совпадения итогового положения. Линия — отрезок через все выровненные узлы с ×-маркерами в их точках; центральная — пунктиром; `vector-effect: non-scaling-stroke`.
- **D7. Сетка.** Применяется только по осям, где снапа не было.
- **D8. Всё включается одним `[alignmentHelper]`.** В `AlignmentHelperSettings` остаётся только `tolerance`.
- **D9. Равные промежутки.** Промежутки между соседними кандидатами, которые перекрываются по перпендикулярной оси и между которыми нет других кандидатов. `center` — середина промежутка, если промежуток больше узла; `duplicate` — тот же промежуток снаружи пары. Узел должен перекрывать «ширину» промежутка. Индикатор — засечки, без чисел, с цепочкой соседних равных промежутков.
- **D10. Прямые рёбра.** Для рёбер между drag-набором (с потомками) и неподвижным узлом, если оба handle фиксированные и на одной оси (`left`/`right` → Y, `top`/`bottom` → X): снап так, чтобы точки handle совпали по этой оси.
- **D11. Модификатор `alignmentBypass`** в `keyboardShortcuts.modifiers`, по умолчанию `Alt`: пока зажат, снап и направляющие выключены (сетка работает).
