# 01. Снап внутри drag-конвейера

Status: resolved
Blocked by: —

Решения D1–D8 из `spec.md`.

- `utils/alignment.ts`: чистые функции — снимок кандидатов, поиск сдвига по осям, точные направляющие для итогового прямоугольника. Юнит-тесты.
- `services/alignment.service.ts`: кандидаты на время drag, снап, сигнал `guides` для отрисовки.
- `DraggableService`: `begin` на старте drag, снап в `moveTo`, сетка по неснапнутым осям, `extent`, направляющие по итоговым позициям, очистка на конце drag.
- `AlignmentHelperComponent`: только рисует `guides`.
- `VflowComponent.alignmentHelper` пишет в настройки.
- Документация страницы и миграция: порог в px, живой снап, правила для родителей.

Критерии: мультивыделение сохраняет взаимное расположение; `(nodeDragEnd)` видит итоговую позицию и нет второго изменения позиции; ребёнок у рамки родителя не получает линию края родителя, но получает центр; ребёнок с `extent: 'parent'` не выходит за родителя; с сеткой узел остаётся на сетке по оси без снапа.

## Answer

Сделано. `utils/alignment.ts` (сцена, `alignmentOffset`, `alignmentGuides`), `services/alignment.service.ts` (`begin`/`snap`/`update`/`end`, сигнал `guides`), `DraggableService.moveTo` снапает сырые позиции всего набора и применяет сетку только по неснапнутым осям, затем `extent`. Auto-pan теперь вызывает тот же `moveTo` для последней точки указателя, вместо отдельного сдвига в обход сетки. `AlignmentHelperComponent` только рисует: линии (центр — пунктир) и один `path` с крестиками и отметками промежутков, размеры в экранных px, `vector-effect: non-scaling-stroke`. Настройка — `FlowSettingsService.alignmentHelper`, `VflowComponent` пишет в неё эффектом.

Уточнения по ходу: центральная линия родителя проходит через весь родитель (иначе у отцентрованного ребёнка она вырождается в точку). Ребёнок у рамки получает и центральную ось родителя по перпендикулярной оси, если она в пределах порога.
