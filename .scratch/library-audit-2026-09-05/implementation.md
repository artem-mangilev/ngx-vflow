# Исправления аудита ngx-vflow

Основание: [первоначальный отчёт](./report.md), исходный commit `84b852e8`, ветка `3.0`.

Все 11 пунктов и перечисленные в отчёте упрощения реализованы.

| Пункт                     | Исправление                                                                                                                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Reparent               | Родитель модели вычисляется из актуального `rawNode.parentId` и индекса узлов, включая добавление ранее отсутствовавшего signal.                                                            |
| 2. Detached notifications | Уведомление вычисляется по разнице последовательных наборов отсоединённых рёбер. Изменение одного ребра не ждёт изменений остальных.                                                        |
| 3. Connection outputs     | Валидация и переходы состояния выполняются независимо от числа подписчиков; connect и reconnect завершаются без подписки на соседний output.                                                |
| 4. Removed handles        | Прежняя геометрия сохраняется только при виртуальном снятии представления того же узла. Настоящее удаление handle очищает путь.                                                             |
| 5. Edge virtualization    | Учитываются границы пути, viewport и zoom threshold. Пересекающие экран линии сохраняются даже при невидимых концах. Для custom curves поддерживаются явные bounds и нативный SVG fallback. |
| 6. Label cache            | Центрирование перенесено в CSS; измерение размеров label и связанные кэши удалены.                                                                                                          |
| 7. Resizer                | Отклонённый `shouldResize` кандидат не меняет принятую геометрию и позиции детей; resizeEnd сообщает последний принятый размер.                                                             |
| 8. Position notifications | Событие содержит только изменившийся узел; неподвижные выделенные узлы больше не дублируются.                                                                                               |
| 9. Model lifecycle        | Effects принадлежат модели и уничтожаются при её удалении из графа, а также при уничтожении flow. Повторное создание selected$ у EdgeModel удалено.                                         |
| 10. removeNodes           | Индексы строятся один раз; каскадное удаление собирает множество id перед финальной фильтрацией. Сохранены порядок, veto и обработка duplicate ids слева направо.                           |
| 11. validEdges            | Проверка принадлежности использует Set. Адресные запросы getNode и fitView используют существующий индекс.                                                                                  |

Удалены четыре cache-сервиса, стратегия preview с единственной реализацией, неиспользуемые styleWidth/styleHeight, ToolbarModel.transform, nonGroups и лишние DI зависимости. Самодельный outputRefToObservable заменён Angular outputToObservable. `NodeModel.pointTransform`, измерение HTML nodes/custom handles и отдельные SVG roots рёбер сохранены согласно их реальным потребителям и ADR.

Регрессии закреплены в `projects/ngx-vflow-lib/src/lib/vflow/audit-regressions.spec.ts`: 17 проверок, включая HTML label при zoom 0.5, реальные D3 resize events, pan/unmount/remount через VflowComponent и поочерёдную виртуализацию концов floating-ребра. Проверка duplicate ids добавлена в существующий graph-operations.spec.ts.

## Проверки

- Typecheck библиотеки — успешно.
- Lint библиотеки — успешно.
- Production build библиотеки и testing entry point — успешно.
- Production build demo/docs — успешно; остаются предупреждения CommonJS от octokit.
- Playwright Chromium — 7/7. Первый запуск пересёкся с production build документации и получил Vite overlay `Cannot find module '@ng-doc/generated'`; последовательный повтор прошёл без изменения браузерных тестов.
- Полный unit-прогон — **193/193**. Первый прогон обнаружил отсутствующий ViewportService в TestBed двух существующих тестов EdgeComponent; provider добавлен, обе проверки прошли отдельно и в полном повторном прогоне.

Синтетический workload исходного аудита, 10 000 узлов: removeNodes раньше занимал 502–535 мс, после изменения в повторных запусках — примерно 5–8 мс; validEdges — около 0,6–0,8 мс вместо 10,7–11,1 мс. Это измерение алгоритмов в Chromium, без рендеринга и создания моделей; абсолютные времена зависят от нагрузки машины.

## Standards

Независимый review не обнаружил нарушений документированных стандартов или actionable code smells. Проверены application-owned graph state, HTML node wrappers, accessibility и SVG interleaving согласно ADR.

## Spec

Первый review нашёл один P2: floating-ребро теряло видимый конец, когда виртуализировался только противоположный. Исправлено: сохранённый виртуальный конец участвует в выборе ближайшей пары handles; настоящее удаление handle видимого конца очищает путь. Добавлены две проверки, воспроизведены до исправления и пройдены после. Повторный review подтвердил закрытие замечания и не нашёл дополнительных ошибок в исправлении.

Итог review: Standards — 0 замечаний; Spec — 1 замечание исправлено, открытых нет.
