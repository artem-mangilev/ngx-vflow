## Стандарты

- **`aria-keyshortcuts`** (WAI-ARIA 1.2): список через пробел, токены через `+`, модификаторы первыми и по именам UI Events (`Control`, `Shift`, `Alt`, `Meta`), `Plus` для `+`, `Space` для пробела; описывает физические клавиши, `%` пишется как `Shift+5`. Только документирует поведение, ничего не включает.
- **WCAG 2.1.4 Character Key Shortcuts (A)**: шорткат из одной печатной клавиши обязан удовлетворять хотя бы одному: его можно выключить, переназначить с добавлением модификатора, или он активен только при фокусе на компоненте. Мотивация: голосовой ввод. Техника G217, провал F99.

## Что повторяется

1. **Две семьи конфигов**: пять именованных пропсов (семейство xyflow, Foblex) и таблица «имя действия → биндинги» со слиянием по имени (ng-diagram, tldraw, Blockly, Node-RED, Obsidian, JupyterLab, Sublime, VS Code). Вторая масштабируется, первая проще для 3–5 действий.
2. **`event.key` доминирует** там, где конфиг пишут люди. `code` живёт как fallback для нелатинских раскладок (tldraw, n8n, Excalidraw, Atom), как явный синтаксис (`[Slash]` в VS Code, `KeyS` в tinykeys/react-hotkeys-hook, `code:` где угодно) или как основа там, где конфига нет (Rete, draw.io). Наш текущий `event.code` для печатных клавиш `Equal`/`Minus` это редкость и реальный дефект для раскладок.
3. **Одиночные символы сравниваются без регистра** почти везде (Foblex, ng-diagram, tldraw, Vue Flow, n8n, yFiles, is-hotkey). React Flow строгий и из-за этого странный.
4. **Платформенный токен** есть у всех зрелых систем: `Mod` (ProseMirror, CodeMirror, Obsidian), `$mod`, `Accel`, `primary` (ng-diagram, Sublime), `CtrlCmd`, `CommandOrControl`, `CTRL_CMD`. Без него пишут оба варианта (tldraw, hotkeys-js, дефолты xyflow). Единственная ловушка: `mod` в react-hotkeys-hook значит «любой из двух».
5. **Несколько биндингов на действие** повсеместны. **Аккорды** почти всегда только «модификаторы + одна клавиша»; одновременное нажатие двух обычных клавиш есть только у xyflow. **Последовательности** (`ctrl+k ctrl+s`, `g i`) только в редакторах кода и Node-RED, ни в одном графовом редакторе.
6. **Модификаторы совпадают точно**: незаданный должен быть отпущен (ng-diagram, tldraw, is-hotkey), с оговоркой для macOS, где Cmd поднимает и meta, и primary.
7. **Отключение**: `null` (xyflow), `[]` (Foblex, ng-diagram, Obsidian), `disabled: true` (JupyterLab), `-command` (VS Code), `noop` (Sublime), `unset!` (Atom), предикат `canExecute` (SDK). Пустой список читается лучше `null`, потому что одинаково выглядит с непустым.
8. **Поля ввода пропускаются везде**, часто с opt-out классом (`.nokey`, `.ignore-key-press-canvas`, `.mousetrap`) и правилом «аккорд с модификатором срабатывает и в поле».
9. **Слушатель**: обычно `document`/`body` с проверкой «редактор содержит activeElement» (ng-diagram, tldraw); на контейнере у Drawflow, LiteGraph. Наш подход «на обёртке и контейнере» ближе ко второму и не имеет багов React Flow с удалением при потере фокуса.
10. **Шпаргалка из конфига** только там, где есть центральный реестр: tldraw, Node-RED, JupyterLab, Obsidian, Atom. Ни один диаграммный SDK её не генерирует. Foblex генерирует анонсы, но текст инструкций статичен.
11. **Область и приоритет** задаются `when`-выражениями (VS Code, Monaco), CSS-селекторами (Lumino, Atom), именованными scope (hotkeys-js, Node-RED) или порядком регистрации с «первый обработавший останавливает» (ProseMirror, Lexical, Tiptap).
12. **Per-platform переопределения** живут рядом с токеном: `{ mac, win, linux }` (CodeMirror, JupyterLab, Chrome), отдельные файлы (Sublime).

## Следствия для ngx-vflow

- Таблица «действие → биндинги» с явным разделением удерживаемых модификаторов и команд подтверждается практикой ng-diagram, tldraw и всех редакторов; форма из пяти пропсов оправдана только пока действий пять.
- Сопоставлять по `event.key` без учёта регистра для одиночных символов, с явным префиксом для физических клавиш (`code:Space`), плюс токен `Mod`. Дефолты `Equal`/`Minus` заменить на `'='`, `'+'`, `'-'`.
- Отключение через `[]`, а не `null`.
- Без последовательностей: ни один графовый редактор их не имеет.
- Из-за WCAG 2.1.4 любой шорткат из одной печатной клавиши (`+`, `-`, `0`) обязан быть отключаемым и переназначаемым; наша активация только при фокусе на обёртке или контейнере уже удовлетворяет третьему условию, но конфиг должен это сохранять.
- Центральный `resolvedShortcuts()` окупается дважды: для генерируемых подсказок (`aria-keyshortcuts`, описания) и для шпаргалки приложения, как у tldraw и Node-RED.
