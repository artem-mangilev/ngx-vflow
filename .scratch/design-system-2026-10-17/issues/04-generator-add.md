# 04. Генератор `add` и сборка шаблонов

Status: needs-triage
Type: task
Blocked by: 03

## Что сделать

- Сборка пакета копирует исходники частей из `libs/ui/src/lib` в `files/` генератора; рукописных шаблонов нет.
- `add <name...>` копирует части в `componentsDir/<name>/`, разрешает зависимости по таблице каталога, переписывает импорты на alias, при Tailwind prefix переписывает классы.
- Существующие файлы не перезаписываются без `--overwrite`; в `vflow-ui.json` пишутся хэши сгенерированных файлов.
- Unit-тесты: зависимости (`controls` → `button`), prefix, конфликт файлов, хэши в манифесте.
