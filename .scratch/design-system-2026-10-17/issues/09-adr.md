# 09. ADR-0010: UI поставляется исходниками через генераторы

Status: needs-triage
Type: task
Blocked by: —

## Что сделать

- Записать решение: копируемые части на Tailwind utilities, генераторы Nx + Angular CLI, CLI повторяет spartan-ng (`@vflow/cli`: `init`, `ui`, `ui-theme`, набор целиком под alias `@vflow/ui`, пресет в пакете и значения тем у потребителя), плотность macOS, токены в пространстве `vui`.
- Указать, что пересматривается из плана 2026-09-12 (двойная поставка CSS, UI без Tailwind, ограничение набора публичных токенов) и что остаётся (ADR-0005 маппинг на core, ADR-0006, ADR-0008 префиксы).
- Отклонённые варианты: обычный CSS в копируемых частях, только Nx, значения токенов в npm, манифест с версиями и хэшами, поддержка Tailwind `prefix()`, установка по частям с entrypoint на часть, директивы `VuiTheme`/`VuiSelected`, чтение выделения из `NODE_REF`, настройка проекта первым `add` без `init`.
