# Дизайн-система @vflow/ui: единый дизайн-код и поставка через генераторы

Статус: направление согласовано 2026-10-17, шкалы токенов — предложение до просмотра превью.
Основание: аудит текущего `libs/ui` (ниже), [план MVP→production](../flow-design-system/plan.md), ADR-0005, ADR-0006, ADR-0008.

## Цель

1. Единый дизайн-код: каждое значение в частях выводится из общей шкалы (цвет, типографика, отступы, размеры, радиусы, elevation, motion). Произвольных значений в частях нет.
2. Универсальный нейтральный визуальный язык в духе Apple (macOS): спокойная нейтральная палитра, один accent, плотная типографика, hairline-разделители, концентрические скругления.
3. Поставка исходников в репозиторий потребителя генераторами (модель shadcn/ui, в Angular — spartan-ng): потребитель владеет кодом и правит его напрямую.

## Решения от 2026-10-17

- **BPMN удалён** (решение пользователя после ревью): entry point `@vflow/ui/bpmn`, страница docs, e2e и стили глифов. Специализированные наборы нотаций в каталог не входят.

- **Модель поставки.** `@vflow/ui` на npm содержит только генераторы и шаблоны. Поведение (handle, selection, viewport API) остаётся в core ngx-vflow — это аналог spartan `brain`; копируемые части — аналог `helm`. В скопированном коде нет логики, которую пришлось бы мержить при обновлении.
- **Стилизация — Tailwind utilities** в копируемом коде. Потребителю нужен Tailwind v4. Это отменяет двойную поставку `styles.css` / `styles.source.css` из решения 2026-09-12 и вариант «UI без Tailwind».
- **Генераторы — Nx + Angular CLI.** Одна реализация на `@nx/devkit`; Angular schematics получаются через `convertNxGenerator`. Работают `nx g @vflow/ui:add node` и `ng g @vflow/ui:add node`, `ng add @vflow/ui` запускает `init`.
- **Токены копируются при `init`** в `vflow-theme.css` проекта потребителя. Тема становится кодом потребителя: правка значений, новые темы, свои имена.
- **Плотность — macOS**: body 13px, caption 11px, контролы 24–28px.

## Визуальный язык

### Принципы

- Нейтральные серые без оттенка; цвет несёт смысл (accent, selection, тоны), а не декор.
- Ноды плоские: hairline-рамка и тень без размытия. Размытые тени и `backdrop-filter` на нодах запрещены — они растрируются заново на каждом шаге pan/zoom (см. комментарий в `node.directive.ts` и [pan/zoom smoothness](../pan-zoom-smoothness-2026-09-26)). «Материал» (полупрозрачный фон + blur) только у плавающих слоёв: controls, toolbar.
- Концентричность: радиус контейнера = радиус вложенного элемента + отступ между ними.
- Все размеры — из шкал ниже; в частях нет arbitrary values (`[...]`), кроме системных цветов forced colors и SVG-свойств без utilities, с комментарием.
- Состояния не только цветом: текст/иконка/форма линии остаются (ADR-0006, forced-colors).

### Цвет

Контраст проверен по WCAG 2 (скрипт в scratchpad сессии); текст ≥ 4.5:1, границы интерактивных состояний ≥ 3:1.

| Токен           | Light                    | Dark                     | Назначение и контраст                                                                                      |
| --------------- | ------------------------ | ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `canvas`        | `#F5F5F7`                | `#1C1C1E`                | Фон flow (→ `--v-background`)                                                                              |
| `surface`       | `#FFFFFF`                | `#2C2C2E`                | Ноды, лейблы, плавающие слои                                                                               |
| `surface-muted` | `rgb(118 118 128 / .12)` | `rgb(118 118 128 / .24)` | Контейнеры, пулы, hover; полупрозрачная заливка Apple fill, поэтому отличима и на `surface`, и на `canvas` |
| `foreground`    | `#1D1D1F`                | `#F5F5F7`                | Основной текст: 16.8 / 12.8                                                                                |
| `muted`         | `#6E6E73`                | `#AEAEB2`                | Вторичный текст, линии рёбер: 5.07 / 6.30                                                                  |

Системный `#007AFF` отклонён: белый текст на нём 4.02:1. Тёмный `#0A84FF` годится для колец и линий, но не как заливка под белым текстом (3.65), поэтому `accent` и `selection` — разные токены. Тоны входят в набор токенов: тема теперь код потребителя, и аргумент 2026-09-12 против расширения публичного контракта к ней не относится.

### Типографика (macOS)

| Роль       | Размер / высота строки | Начертание | Где                                       |
| ---------- | ---------------------- | ---------- | ----------------------------------------- |
| `caption`  | 11 / 14px              | regular    | meta, статусы, edge label, external label |
| `body`     | 13 / 18px              | regular    | содержимое, поля, кнопки (semibold)       |
| `headline` | 13 / 18px              | semibold   | заголовки нод и контейнеров               |

`font-sans`: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`; `font-mono`: `ui-monospace, "SF Mono", Menlo, monospace` (типы полей ERD). Все размеры в px — граф масштабируется zoom, а не root font-size.

Правила текста (2026-10-17): части сами задают семейство, размер, высоту строки и насыщенность и сбрасывают `letter-spacing` приложения; область темы включает `antialiased`. Элементы заголовка выравниваются по базовой линии первой строки title (слот иконки получает нулевую опорную строку). Роль `title` 15/20 удалена: заголовок контейнера — headline. Типографика контента внутри нод остаётся за потребителем; шрифт docs — системный, как у частей.

### Отступы и размеры

- Сетка 4pt: именованные ключи `--spacing-vui-N = N × --vui-space` (N = 0–8, 10, 12, 14, 16), utilities `p-vui-3`, `size-vui-7`. Глобальный `--spacing` потребителя не переопределяется.
- Высота контролов: `sm` 24px (иконки в toolbar), `md` 28px (кнопки, controls), `lg` 32px.
- Строка поля: 32px; внутренние отступы ноды 12px; gap 8px.
- Порт: 16px (4 шага) с рамкой 2px цвета `surface`, видимая точка 12px. Порт — сама зона захвата (увеличенной hit area у core нет), поэтому меньше прежних 14px не делаем.

### Радиусы (концентрические)

| Токен            | Значение | Где                                                 |
| ---------------- | -------- | --------------------------------------------------- |
| `radius-control` | 6px      | Кнопки, control button, edge label                  |
| `radius-surface` | 10px     | Нода, контейнер, toolbar, controls (= 6 + отступ 4) |
| `radius-full`    | 9999px   | Порт, точка busy-статуса                            |

### Elevation

| Уровень               | Light                                                         | Dark                                                              | Где                |
| --------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------ |
| 0 — `shadow-node`     | `0 1px 0 rgb(0 0 0 / 0.04)`                                   | `0 1px 0 rgb(0 0 0 / 0.3)`                                        | Ноды, без размытия |
| 1 — `shadow-floating` | `0 4px 16px rgb(0 0 0 / 0.12), 0 0 0 0.5px rgb(0 0 0 / 0.08)` | `0 4px 16px rgb(0 0 0 / 0.5), 0 0 0 0.5px rgb(255 255 255 / 0.1)` | Toolbar, controls  |
| Материал              | `surface` 80% + `backdrop-blur 20px saturate 180%`            | то же                                                             | Только уровень 1   |

### Выделение, фокус, motion

- Выделение ноды/контейнера: `outline 2px selection`, offset 2px, радиус `radius-surface`; ребро — `stroke selection`.
- Focus-visible контролов: то же кольцо. Core-фокус получает `--v-focus: selection`, `--v-focus-radius: radius-surface`.
- Один `--vui-duration` 150ms и `--vui-ease` `cubic-bezier(0.25, 0.1, 0.25, 1)`; при `prefers-reduced-motion` пульс статуса выключен.
- Forced colors сохраняют текущие правила (`Highlight`, `ButtonText`, `CanvasText`).

### Три параметра вместо каталога значений (реализовано в 01–02)

Все шкалы выводятся в `@theme inline` из `--vui-font-size` (13px), `--vui-space` (4px) и `--vui-radius` (6px): caption/title = body ∓ 2px, высоты строк = размер + 1/5/7px, `radius-surface` = `--vui-radius + --vui-space` (концентричность сохраняется при любом переопределении). `inline` вставляет выражение в utility, поэтому переопределение на любом элементе пересчитывает части внутри него.

Дефолтная тема Tailwind не импортируется: `p-3`, `text-xs`, `rounded-lg`, `min-w-0` не генерируются. `check-styles` проверяет, что каждый класс каждой части есть в собранном CSS, и запрещает arbitrary values вне белого списка (системные цвета, SVG-свойства без utilities, локальные переменные частей из токенов темы).

## Tailwind в проекте потребителя

- `vflow-theme.css` регистрирует токены через `@theme` в собственном пространстве `vui`: `--color-vui-surface`, `--radius-vui-surface`, `--text-vui-body` и т.д. Utilities — `bg-vui-surface`, `rounded-vui-surface`, `text-vui-body`. Это исключает коллизии с темой приложения (`bg-surface`, `bg-background` у shadcn-подобных тем) и не требует глобального Tailwind `prefix()`, который настраивает потребитель.
- Значения тем — CSS-переменные `--vui-*` в `[data-vui-theme='light'|'dark']`; `@theme inline` ссылается на них, поэтому смена темы — только смена переменных.
- Маппинг на core `--v-*` в области темы сохраняется (ADR-0005): импорт темы не перекрашивает flow вне `[data-vui-theme]`.
- Скопированные файлы лежат в `src/` потребителя, Tailwind находит их автоматическим source detection; `@source` для `node_modules` не нужен.
- Если у потребителя настроен Tailwind `prefix(x)`, генератор переписывает классы в шаблонах (`x:bg-vui-surface`). Значение prefix читается из `vflow-ui.json` (опция `init`), а не угадывается.
- Длинные строки классов в `host.class` группируются по назначению (layout / цвет / состояния / forced-colors), чтобы файл было легко править.

## Генераторы

| Генератор         | Что делает                                                                                                                                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `init` (`ng add`) | Проверяет Tailwind v4 (ошибка с инструкцией, если нет); пишет `vflow-theme.css`, добавляет его импорт в глобальные стили после `@import 'tailwindcss'`; пишет `vflow-ui.json` (версия, `componentsDir`, Tailwind prefix, alias импорта) |
| `add <name...>`   | Копирует части в `componentsDir/<name>/`, разрешает зависимости (`controls` → `button`), переписывает импорты на alias потребителя; существующий файл не перезаписывает без `--overwrite`                                               |

- В манифест записываются версия и хэш каждого сгенерированного файла: будущий `update` сможет отличить нетронутые файлы от изменённых. Сам `update` в этот объём не входит.
- Имена селекторов и классов остаются `vui*` / `Vui*` (ADR-0008); опции смены префикса нет.
- Каталог для `add`: `theme`, `selected`, `node`, `field`, `container`, `text`, `port`, `status`, `edge`, `toolbar`, `external-label`, `button`, `controls`.

## Источник истины в репозитории

- Компилируемые исходники частей остаются в `libs/ui/src/lib` — docs и e2e работают на них, как сейчас (tsconfig paths `@vflow/ui`).
- Сборка пакета копирует эти исходники в `files/` генератора и подставляет токены импорта/prefix; рукописных копий-шаблонов нет.
- Опубликованный пакет: генераторы, `generators.json`, `collection.json`, шаблоны. Runtime-экспортов и `styles.css` нет. `@vflow/ui` ещё не публиковался, поэтому миграции npm-потребителей нет.
- Docs: у каждой части — команда установки и исходник файла (как у shadcn/spartan); страница токенов показывает шкалы в обеих темах.

## Не входит

- `update`/`diff` генератор (только манифест для него).
- Дополнительные темы кроме light/dark.
- Новые части каталога и изменения core-поведения.
- Вариант без Tailwind.
