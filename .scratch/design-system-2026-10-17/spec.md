# Дизайн-система @vflow/ui: единый дизайн-код и поставка через генераторы

Статус: направление согласовано 2026-10-17, шкалы токенов — предложение до просмотра превью.
Основание: аудит текущего `libs/ui` (ниже), [план MVP→production](../flow-design-system/plan.md), ADR-0005, ADR-0006, ADR-0008.

## Цель

1. Единый дизайн-код: каждое значение в частях выводится из общей шкалы (цвет, типографика, отступы, размеры, радиусы, elevation, motion). Произвольных значений в частях нет.
2. Универсальный нейтральный визуальный язык в духе Apple (macOS): спокойная нейтральная палитра, один accent, плотная типографика, hairline-разделители, концентрические скругления.
3. Поставка исходников в репозиторий потребителя генераторами (модель shadcn/ui, в Angular — spartan-ng): потребитель владеет кодом и правит его напрямую.

## Решения от 2026-10-17

- **BPMN удалён** (решение пользователя после ревью): entry point `@vflow/ui/bpmn`, страница docs, e2e и стили глифов. Специализированные наборы нотаций в каталог не входят.

- **Модель поставки.** На npm публикуется `@vflow/cli`: генераторы, шаблоны частей и Tailwind-пресет. Части копируются в репозиторий потребителя одной библиотекой и импортируются через alias `@vflow/ui`. Поведение (handle, selection, viewport API) остаётся в core ngx-vflow — это аналог spartan `brain`; копируемые части — аналог `helm`. В скопированном коде нет логики, которую пришлось бы мержить при обновлении.
- **Стилизация — Tailwind utilities** в копируемом коде. Потребителю нужен Tailwind v4. Это отменяет двойную поставку `styles.css` / `styles.source.css` из решения 2026-09-12 и вариант «UI без Tailwind».
- **Генераторы — Nx + Angular CLI.** Одна реализация на `@nx/devkit`; Angular schematics получаются через `convertNxGenerator`. Работают `nx g @vflow/cli:ui node` и `ng g @vflow/cli:ui node`.
- **Значения токенов копируются** `init` / `ui-theme` в глобальный stylesheet потребителя; регистрация токенов в Tailwind (`@theme inline`, маппинг на core) — пресет из пакета. Значения и новые темы — код потребителя, пресет обновляется вместе с пакетом.
- **Плотность — macOS**: body 13px, caption 11px, контролы 24–28px.
- **CLI повторяет spartan-ng (2026-10-18).** `@vflow/cli` и пресет в нём подтверждены пользователем; пакет общий для vflow (в будущем — генератор скиллов). Генераторы, конфиг, раскладка частей и синхронизация шаблонов скопированы с `@spartan-ng/cli` 1.8; отличия перечислены в разделе «Генераторы».
- **Набор ставится целиком (2026-10-18).** Части — одна система в 11 файлах (~425 строк) без npm-зависимостей, поэтому выбора частей, таблицы зависимостей и entrypoint на часть нет. Конфиг — `vflow.json` с разделом `ui`: файл общий для будущих возможностей CLI (скиллы).
- **Выделение — вход части (2026-10-18).** `vuiNode`, `vuiContainer`, `vuiEdge` принимают `selected`; потребитель передаёт `ctx.selected()` (и, если хочет, `ctx.preselected()`) или своё состояние. Части не читают `NODE_REF`/`EDGE_REF`. Директивы `VuiSelected` и `VuiTheme` удалены: тема — атрибут `data-vui-theme` на любом элементе, включая `<html>` в `index.html`.

## Визуальный язык

### Принципы

- Нейтральные серые без оттенка; цвет несёт смысл (accent, selection, тоны), а не декор.
- Ноды плоские: hairline-рамка и тень без размытия. Размытые тени и `backdrop-filter` на нодах запрещены — они растрируются заново на каждом шаге pan/zoom (см. комментарий в `node.directive.ts` и [pan/zoom smoothness](../pan-zoom-smoothness-2026-09-26)). «Материал» (полупрозрачный фон + blur) только у плавающих слоёв: controls, toolbar.
- Концентричность: радиус контейнера = радиус вложенного элемента + отступ между ними.
- Все размеры — из шкал ниже; в частях нет arbitrary values (`[...]`), кроме системных цветов forced colors и SVG-свойств без utilities, с комментарием.
- Состояния не только цветом: текст/иконка/форма линии остаются (ADR-0006, forced-colors).

Тоны входят в набор токенов: тема теперь код потребителя, и аргумент 2026-09-12 против расширения публичного контракта к ней не относится.

### Типографика (macOS)

| Роль       | Размер / высота строки | Начертание | Где                                       |
| ---------- | ---------------------- | ---------- | ----------------------------------------- |
| `caption`  | 11 / 14px              | regular    | meta, статусы, edge label, external label |
| `body`     | 13 / 18px              | regular    | содержимое, поля, кнопки (semibold)       |
| `headline` | 13 / 18px              | semibold   | заголовки нод и контейнеров               |

`font-sans`: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`. `font-mono` удалён 2026-10-17: ни одна часть и ни одно демо его не использовали. Все размеры в px — граф масштабируется zoom, а не root font-size.

Правила текста (2026-10-17): части сами задают семейство, размер, высоту строки и насыщенность и сбрасывают `letter-spacing` приложения; область темы включает `antialiased`. Элементы заголовка выравниваются по базовой линии первой строки title (слот иконки получает нулевую опорную строку). Слот `vuiIcon` универсальный (2026-10-17): минимум 16px в ширину и строка в высоту, растёт по содержимому; опорная строка центрирована в слоте, поэтому центр слота совпадает с центром первой строки title при любом размере (иконка 12–40px, аватар, инициалы). Ставится на обёртку: на `svg`/`img` псевдоэлемент не рисуется. Роль `title` 15/20 удалена: заголовок контейнера — headline. Типографика контента внутри нод остаётся за потребителем; шрифт docs — системный, как у частей.

### Отступы и размеры

- Сетка 4pt: именованные ключи `--spacing-vui-N = N × --vui-space` (N = 0–8; 10–16 удалены 2026-10-17 — их не использовала ни одна часть), utilities `p-vui-3`, `size-vui-7`. Глобальный `--spacing` потребителя не переопределяется.
- Высота контролов: `sm` 24px (иконки в toolbar), `md` 28px (кнопки, controls), `lg` 32px.
- Строка (`vuiRow`): 32px; внутренние отступы ноды 12px; gap 8px.
- Порт: 16px (4 шага) с рамкой 2px цвета `surface`, видимая точка 12px. Порт — сама зона захвата (увеличенной hit area у core нет), поэтому меньше прежних 14px не делаем.

| ---------------- | -------- | --------------------------------------------------- |
| `radius-control` | 6px      | Кнопки, control button, edge label                  |
| `radius-surface` | 10px     | Нода, контейнер, toolbar, controls (= 6 + отступ 4) |
| `radius-full`    | 9999px   | Порт, точка busy-статуса                            |

### Elevation

| Уровень               | Light                                                         | Dark                                                              | Где                |
| --------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------ |
| 0 — `shadow-node`     | `0 1px 0 rgb(0 0 0 / 0.04)`                                   | `0 1px 0 rgb(0 0 0 / 0.3)`                                        | Ноды, без размытия |
| 1 — `shadow-floating` | `0 4px 16px rgb(0 0 0 / 0.12), 0 0 0 0.5px rgb(0 0 0 / 0.08)` | `0 4px 16px rgb(0 0 0 / 0.5), 0 0 0 0.5px rgb(255 255 255 / 0.1)` | Toolbar, controls  |
| Материал              | `surface` 80% + `backdrop-blur 20px saturate 180%`            | то же                                                             | Только уровень 1   |

### Выделение, фокус, motion

- Выделение ноды/контейнера: `outline 2px selection`, offset 2px, радиус `radius-surface`; ребро — `stroke selection`.
- Focus-visible контролов: то же кольцо. Core-фокус получает `--v-focus: selection`, `--v-focus-radius: radius-surface`.
- Один `--vui-duration` 150ms и `--vui-ease` `cubic-bezier(0.25, 0.1, 0.25, 1)`; при `prefers-reduced-motion` пульс статуса выключен.
- Forced colors сохраняют текущие правила (`Highlight`, `ButtonText`, `CanvasText`).

### Три параметра вместо каталога значений (реализовано в 01–02)

Все шкалы выводятся в `@theme inline` из `--vui-font-size` (13px), `--vui-space` (4px) и `--vui-radius` (6px): caption/title = body ∓ 2px, высоты строк = размер + 1/5/7px, `radius-surface` = `--vui-radius + --vui-space` (концентричность сохраняется при любом переопределении). `inline` вставляет выражение в utility, поэтому переопределение на любом элементе пересчитывает части внутри него.

Дефолтная тема Tailwind не импортируется: `p-3`, `text-xs`, `rounded-lg`, `min-w-0` не генерируются. `check-styles` проверяет, что каждый класс каждой части есть в собранном CSS, и запрещает arbitrary values вне белого списка (системные цвета, SVG-свойства без utilities, локальные переменные частей из токенов темы).

## Tailwind в проекте потребителя

- Пресет `@vflow/cli/ui-preset.css` регистрирует токены через `@theme inline` в собственном пространстве `vui`: `--color-vui-surface`, `--radius-vui-surface`, `--text-vui-body` и т.д. Utilities — `bg-vui-surface`, `rounded-vui-surface`, `text-vui-body`. Это исключает коллизии с темой приложения (`bg-surface`, `bg-background` у shadcn-подобных тем) и не требует глобального Tailwind `prefix()`, который настраивает потребитель.
- Значения тем — CSS-переменные `--vui-*`: шкалы и motion один раз в `:root`, цвета и тени — одинаковым набором ключей в `[data-vui-theme='light'|'dark']` (`check-styles` сверяет наборы); `@theme inline` ссылается на них, поэтому смена темы — только смена переменных.
- Маппинг на core `--v-*` в области темы сохраняется (ADR-0005): импорт темы не перекрашивает flow вне `[data-vui-theme]`.
- Скопированные части лежат в репозитории потребителя (`componentsPath`), Tailwind находит их автоматическим source detection; `@source` для `node_modules` не нужен.
- Tailwind `prefix()` потребителя не поддерживается, как и у spartan: пространство `vui` уже исключает коллизии.
- Длинные строки классов в `host.class` группируются по назначению (layout / цвет / состояния / forced-colors), чтобы файл было легко править.

## Генераторы

Поведение скопировано с `@spartan-ng/cli` 1.8 (`init`, `ui`, `ui-theme`, `components.json`). Поддерживаются Angular 20, 21 и 22 (peers `ngx-vflow`; проверено `nx run cli:smoke` на свежих Angular CLI 20–22 и Nx 21–22). Потребитель ставит `npm i -D @vflow/cli` (зависимости — `nx`, `@nx/devkit`, `enquirer`; `@nx/angular` — optional peer, нужен только в Nx); Tailwind v4 — предусловие, генераторы его не ставят и не проверяют (как spartan: docs ссылаются на официальный гайд Tailwind для Angular). `ng-add` нет.

| Генератор  | spartan    | Что делает                                                                                                                                                                                     |
| ---------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `init`     | `init`     | Добавляет `ngx-vflow` в `dependencies`, если его нет (аналог `@spartan-ng/brain`), и запускает `ui-theme`                                                                                      |
| `ui-theme` | `ui-theme` | Выбор приложения (`--project`, вопрос, единственное приложение — без вопроса); stylesheet (`--stylesEntryPoint` или поиск); импорт пресета после ведущих `@import`; значения тем в конец файла |
| `ui`       | `ui`       | Конфиг, копирование всего набора одной библиотекой, tsconfig path, npm-зависимости                                                                                                             |

### `ui-theme`

- Stylesheet ищется как у spartan: `styles.css|scss|sass|less` в `sourceRoot` проекта, затем первый файл проекта из `build.options.styles`; не нашёлся — ошибка с подсказкой про `--stylesEntryPoint`.
- `@import '@vflow/cli/ui-preset.css';` вставляется сразу после ведущих `@charset` / `@import` / `@layer …;`, чтобы `@import 'tailwindcss'` шёл первым и CSS оставался валидным.
- В конец файла пишутся блоки `:root, [data-vui-theme='light'] { --vui-*… }` и `[data-vui-theme='dark'] { --vui-*… }`.
- Повторный запуск ничего не дублирует: импорт пресета и блок `[data-vui-theme='dark']` уже есть — генератор пишет об этом и оставляет файл; значения правят на месте.
- Ведущие комментарии (`/* You can add global styles… */` из `ng new`, `//` в Sass) пропускаются, поэтому пресет встаёт после `@import 'tailwindcss'`, а не над ним.
- Отличия от spartan: темы одна пара light/dark, поэтому нет выбора темы и опции `--theme`; нет `--prefix` (тема уже ограничена `[data-vui-theme]`); не переписываются Tailwind-импорты и не добавляется `@layer base` для `body` — части не зависят от слоёв и не стилизуют страницу.

### `ui`

- **Конфиг `vflow.json`** — аналог `components.json`, общий для возможностей CLI; UI читает и валидирует только раздел `ui`, ошибки печатаются таблицей. Раздел создаёт первый запуск `ui` (не `init`) по вопросам: `componentsPath` (по умолчанию `libs/ui`, без вопроса при `--directory`), `importAlias` (по умолчанию `@vflow/ui`), в Nx ещё `buildable` (по умолчанию `true`).

  ```json
  { "ui": { "componentsPath": "libs/ui", "importAlias": "@vflow/ui", "buildable": true } }
  ```

- **Набор целиком**: аргумента с именем части нет. Файлы ложатся в `<componentsPath>/src/index.ts` и `src/lib/*`; части импортируют друг друга относительно, как в `libs/ui`.
  - Angular CLI: path `<importAlias>` → `./<componentsPath>/src/index.ts` в корневом tsconfig и `<componentsPath>/src/**/*.ts` в `include` `tsconfig.app.json`.
  - Nx: одна Angular-библиотека в `componentsPath` с import path `<importAlias>` (`buildable` из конфига). Файлы, которые пишет генератор библиотек Nx (`src/lib/*`, `src/index.ts`), заменяются набором; правила ESLint библиотеки не меняются — префикс селекторов `vui` задаётся при создании.
  - Режим Angular CLI включает флаг `angularCli`, который передаёт schematic-обёртка (05), как у spartan.
- **Повторный запуск** (alias уже есть в tsconfig paths, как признак установки у spartan; например, после обновления `@vflow/cli`) создаёт недостающие файлы и не трогает существующие; `index.ts` не переписывается — генератор печатает части, которых в нём нет. Перезаписи и `--overwrite` нет.
- **npm-зависимости** (`ngx-vflow`) добавляются в `package.json`, установка — задачей генератора.

### Каталог

`node`, `row` (бывший `field`, переименован 2026-10-17), `group` (с `vuiGroupHeader`; бывший `container`, переименован 2026-10-18 — название не говорило, что это группа нод), `text`, `port`, `status`, `edge`, `toolbar`, `button`, `controls`. `external-label` удалён 2026-10-17 (наследие BPMN), `theme` и `selected` — 2026-10-18 (директивы заменены атрибутом темы и входом `selected`). Имена селекторов и классов остаются `vui*` / `Vui*` (ADR-0008); `index.ts` экспортирует директивы и массив `Vui`.

## Источник истины в репозитории

Раскладка как у spartan (`libs/helm` + `libs/cli` + `libs/tools`):

- `libs/ui` — приватная библиотека `@vflow/ui` с одним entrypoint и без сборки; docs и e2e импортируют `@vflow/ui` — тот же путь, что у потребителя после `ui`.
- `libs/cli` — публикуемый `@vflow/cli`: `generators.json` с секциями `generators` и `schematics`, `compat.ts` на генератор, шаблоны, `ui-preset.css`; релизится одной версией с `ngx-vflow` (тег `release`), так как `init` и `ui` ставят `ngx-vflow` в версии CLI.
- Скрипт `libs/ui/scripts/sync-cli.mjs` (`nx run ui:sync-cli`, аналог `hlm-to-cli-generator`; скрипт, а не Nx-генератор, как остальные скрипты `libs/ui`) копирует `libs/ui/src` в `libs/cli/src/generators/ui/files` с суффиксом `.template` (`public-api.ts` → `src/index.ts`), `ui-preset.css` в корень `libs/cli` и `ui-theme.css` в `libs/cli/src/generators/ui-theme`. Копии дословные: импорты внутри набора относительные. Результат коммитится; `ui:check-cli` в CI падает на расхождении и на шаблоне без исходника.
- Пресет и значения тем — `libs/ui/src/ui-preset.css` и `ui-theme.css`; `styles.css` библиотеки импортирует оба. Правила пресета лежат в `@layer base` (у потребителя ниже utilities, неслоёные стили приложения побеждают). `check-styles` дополнительно собирает путь потребителя: полный `@import 'tailwindcss'`, пресет, значения и части.
- Docs: у каждой части — исходник файла; страница конфига `vflow.json`; страница токенов показывает шкалы в обеих темах.

## Не входит

- `healthcheck`, `info` и `migrate-*` генераторы spartan — появятся с первыми breaking changes частей.
- Генератор скиллов для агентов — будущий генератор того же `@vflow/cli` (решение 2026-10-18: пакет общий для vflow, не только для UI; поэтому UI-генераторы называются `ui`, `ui-theme`, а пресет — `ui-preset.css`).
- Дополнительные темы кроме light/dark.
- Новые части каталога и изменения core-поведения.
- Вариант без Tailwind.
