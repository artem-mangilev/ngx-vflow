# 01. Инкрементальный culling через пространственный индекс

Status: resolved
Type: task
Blocked by: —

`NodeRenderingService.viewportNodes` был computed с ~15 000 продюсеров (globalPoint, width, height каждого из 4 900 узлов) и перезапускался на каждом кадре pan/zoom; эффект `EdgeRenderingService` читал `bounds()` всех 4 899 рёбер. На 144 Гц это 10–22 мс JS на кадр в dev при 25 видимых узлах: демо Virtualization при zoom 3 теряло 209 из 399 кадров pan. Кроме того `shouldLoad` при `lazyLoadTrigger: 'viewport'` делал `viewportNodes().includes(this)` — O(n) на узел, O(n²) на смену вьюпорта.

Решение: `utils/spatial-index.ts` (равномерная сетка 512 единиц, большие прямоугольники в отдельном списке, запрос стоит O(ячеек + кандидатов)) и `services/viewport-culling.service.ts`: по одному tracker-эффекту на сущность (3–4 продюсера, обновляет её запись в индексе и проверяет членство против текущих границ), один эффект вьюпорта (запрос индекса, diff с множеством `inside`). Вход в вьюпорт сообщается сразу; выход, вызванный жестом, — на `viewportChangeEnd$` или через 300 мс паузы, чтобы не тратить recalc style посреди движения на то, что уже за экраном. Изменение геометрии самой сущности сообщается сразу в обе стороны (за ним не следует конец жеста). `viewportNodes` остался как ленивый computed по `inViewport` (для alignment helper), `shouldLoad` читает `inViewport()`.

## Answer

Сделано. Замер (headed Chromium, 144 Гц, DPR 2, dev-сервер, `tools/frametrace.mjs`, Virtualization, zoom 3, pan 90 шагов по 7 мс):

| Метрика pan         | До                       | После 01                 |
| ------------------- | ------------------------ | ------------------------ |
| Потерянных кадров   | 209 из 399               | 7 из 293                 |
| Главный поток занят | 4 887 мс из 5 818 (84 %) | 1 059 мс из 2 152 (49 %) |
| p90 интервала rAF   | 19.4 мс                  | 7.8 мс                   |

В фазе zoom-in recalc style за 10 052 элемента (массовое скрытие узлов, 17.5 мс в одном кадре) ушёл из жеста: скрытие происходит один раз по его окончании. Unit-тесты: `spatial-index.spec.ts`, два новых теста в `css-virtualization.spec.ts` (отложенное скрытие до конца жеста и по паузе; немедленное для сдвинутого узла); тесты audit-regressions активируют culling через новый сервис и `sync()`.

A/B `bench.mjs` (headless dev, 5 прогонов, медиана, вместе с 03 и 05): pan script 486 → 45 мс, zoom-out script 1 347 → 200 мс и без длинных кадров (p90 47 → 17 мс), загрузка 2 734 → 2 463 мс, куча +7 MB.
