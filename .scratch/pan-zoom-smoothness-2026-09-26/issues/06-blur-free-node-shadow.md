# 06. Тень узла `@vflow/ui` без блюра

Status: resolved
Type: task
Blocked by: —

При zoom-out на большой панели (DPR 2, 144 Гц) с сотнями видимых узлов кадры по 35–60 мс, главный поток пуст, GPU занят 17–38 мс на кадр: каждый шаг масштаба и сдвиг заново растрируют видимые узлы. CSS-эксперименты (spec.md, раздел «Zoom-out на большой панели») показали, что стоимость почти целиком в `box-shadow: 0 3px 10px #0000000a` на каждом `vui-node`: без тени zoom-out 30 из 74 → 4 из 133 потерянных кадров, pan 20 из 250 → 2 из 231; скрытие рёбер почти не помогает; тень с блюром 2 px укладывается в бюджет, но даёт одиночные GPU-остановки ~300 мс.

## Answer

`libs/ui/src/lib/node.directive.ts`: `vui:shadow-[0_1px_0_#0000000f]` — тень без блюра. Прогон на демо после правки: zoom 3 → 0.5 — 5 из 131, pan 2 из 231; zoom 3 → 0.25 (391 узел) — 17 из 131 и 3 из 309 против 40 из 67 и 62 из 310 в базе. Документация: страница Virtualization (стоимость растра видимого содержимого, правило «без блюра в покое») и Design system (тень оболочки узла). e2e design-system и stress-rendering зелёные.
